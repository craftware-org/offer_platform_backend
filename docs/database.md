# Database

PostgreSQL 17 + PostGIS 3.5 ([ADR-0004](adr/0004-postgresql-postgis.md)), accessed through Drizzle ORM 0.45 ([ADR-0005](adr/0005-drizzle-orm.md)).

## Conventions

| Topic | Rule |
|---|---|
| Primary keys | UUID v7, generated by the application |
| Timestamps | `timestamptz`, UTC; `created_at`, `updated_at` on mutable tables |
| Money | `bigint` paise (from Phase 3) |
| Deletion | Business data is never hard-deleted; status columns + `deleted_at` |
| Ownership | Each module defines its tables in its own `*.schema.ts` and is the only code that reads or writes them ([ADR-0002](adr/0002-modular-monolith.md)) |
| Migrations | SQL files in `apps/api/database/migrations/`, generated by drizzle-kit and reviewed; applied by `pnpm db:migrate` (the same runner in dev, CI and production) |

Extensions (migration `0000_extensions`): `postgis`, `pg_trgm`, `citext`, `unaccent`.

## Tables (Phase 1)

| Table | Owner module | Purpose |
|---|---|---|
| `users` | users | Accounts. `phone` is E.164, unique; cleared on account deletion. Status `ACTIVE`, `SUSPENDED` or `DELETED` |
| `roles`, `permissions`, `role_permissions` | access-control | Reference data synced from the catalog |
| `user_roles` | access-control | Which user has which role, and who granted it |
| `otp_challenges` | auth | Login codes (HMAC only), attempts, expiry, consumption |
| `refresh_tokens` | auth | Session tokens (SHA-256 only), rotation chain (`family_id`, `replaced_by_id`) |
| `audit_logs` | audit | Append-only record of administrative and security events |

## Local development

`docker compose up -d` starts PostgreSQL on `127.0.0.1:5432`. The PostGIS image also installs `postgis_tiger_geocoder` and `postgis_topology` in the local database. These are **not** used by the application and are not created by our migrations, so production will not have them.
